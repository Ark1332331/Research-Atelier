技术要点：
- 路由文件用 `@/lib/...` 别名导入，node --experimental-strip-types 不能直接解析 → 写 tests/helpers/alias-hooks.mjs（module.register loader，把 "@/x" 重写为 file URL，补 .ts 扩展/index 解析），npm test 用 `--import ./tests/helpers/alias-hooks.mjs` 注册
- store.ts 的 DATA_DIR 在模块加载时读 RA_DATA_DIR → 每个测试文件顶层先 process.env.RA_DATA_DIR = <tmp> 再动态 import 路由
- 沙箱：node:test 每文件建临时目录（os.tmpdir + 随机），种子最小 projects.json/learning 数据（可参照 data/ 结构与 store.ts 读写约定）
- 避开网络：sync 路由的 AI 动作（refreshState 会走 sync-explain→DeepSeek）只测其 400/404 分支与不触发 AI 的分支；不 mock 网络
- projects 路由：GET 列表/带 id、POST createProject 正常 + 非法 module 400 + 不存在项目 404
- handoff 路由：POST 有项目 → 生成交接词文本（断言包含论文标题等），无 projectId/项目不存在 → 404
- sync 路由：POST 空 body/非 JSON → 400，projectId 缺失 → 400，不存在项目 → 404；rebuildHistory 无会话 → 400
</context>
