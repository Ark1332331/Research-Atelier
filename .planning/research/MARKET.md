# Research: 开源学习/科研助手市场对标（2025-2026）

来源：Web 调研（Zotero 生态、Obsidian、Anki/FSRS、PaperQA2/OpenScholar、论文复现工具、中文科研工具）。完整来源链接见会话记录。

## Table Stakes（按重要性）
1. 本地 PDF 阅读 + 高亮/标注/笔记回链原文（必须）
2. 中英对照/划词翻译 + 学科术语库（中文用户必须，对标小绿鲸/ReadPaper）
3. AI 问答且答案**带句子级引文定位**（反幻觉是生死线）
4. 文献库管理（够用即可，不必追平 Zotero）
5. 术语卡片 + SRS（建议直接内置 FSRS，不自研）
6. 多篇对比/综述（中期）
7. 复现工作流（远期）

## 值得借鉴的差异化设计
1. **句子级引用锚定**（Beaver/PaperQA2）：AI 回答点击即跳回 PDF 原文位置。
2. **标注一键变卡片**：打通"阅读→卡片"，解决 Anki 制卡负担（弃坑头号原因，7 天留存仅约 23%）。
3. **诚实的不确定性**（paper2code）：AI 明示哪些来自论文原文、哪些是推断。
4. **本地优先/离线**（PapersGPT+Ollama、Smart Connections）：隐私 + 零 API 成本。
5. **批量 prompt 指令集**（Awesome GPT/Copilot）："提炼方法/找局限/对比两篇"一键化。

## 常见失败模式（必须规避）
- **配置地狱**：填 API Key、改配置文件，入门者第一晚流失。
- **制卡/维护负担**：卡片堆积→复习积压→罪恶感→卸载。
- **工具高于内容**：用户折腾工具而非学习。
- **AI 幻觉毁信任**：编造一次即弃用。
- **功能大而全 vs 工作流断裂**：没有工具覆盖全流程；对新手，**把"读一篇论文"的单一闭环做顺**比铺全功能更重要。

## 对本项目的含义
- 已有：PDF 阅读+标注+翻译（TS1/TS2 ✓）、术语卡+自研 SRS（TS5 部分）、文献发现。
- 缺口：AI 讲解引用锚定（TS3）、FSRS、标注→一键制卡、配置引导、Windows 可安装分发。
