# 用户观察画像

范围：只实现用户提出的独立画像及现有讲解策略之间的关联，不新增工作台、复习队列、阅读目标、课程材料入口或复现流程。

- 复用现有持久化后台观察者。画像描述用户自述背景、当前目标、知识经历、具体卡点和学习条件；讲解策略描述针对这些事实应怎样解释。两者分开存储。
- 观察者从真实用户话语提出带原话依据的待确认画像，并给策略附画像依据及理由。助手回答、引用材料、选词和工具报错不能单独证明用户能力。
- 用户可查看、直接添加、编辑、确认、停用、拒绝和删除画像。手动修改立即生效；推断经确认才用于回答。保留版本及依据，旧策略不能继续依赖已改动或已停用画像。
- 已确认画像进入相关回答上下文；每次回答保存实际使用的画像与策略版本。所有对话入口进入同一个观察队列，补齐划线追问及术语复述。翻译操作本身不推断画像。
- 旧数据兼容；暂停观察、暂停应用、并发编辑、删除期间的模型请求不能覆盖用户操作。没有模型配置时可手动管理画像，后台失败可见、可重试。

实现顺序：画像类型与事务操作 → 观察器结构化输出及关联校验 → 对话入口和回答记录 → 可编辑画像界面和策略依据 → 隔离数据测试、浏览器交互检查、全量检查及构建。
