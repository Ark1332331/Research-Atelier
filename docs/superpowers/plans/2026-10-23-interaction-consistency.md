# 交互一致性检查与修复

用户要求直接从实际使用流程排查和优化，不再等待用户逐个体验反馈。

## 已确认的问题
- PDF 删除分散在 paper/library 两条路由，均未解除项目中的 paperSlug；外部项目没有删除入口。
- 首页导航只保存在组件 state，进入阅读器后返回/刷新丢失项目上下文。
- 原 AI 窗口有独立拖拽代码，允许大半窗口离屏；追问和翻译窗口固定位置，样式/关闭行为不统一。
- 关闭 AI 窗口卸载聊天组件，当前对话需要手动寻找历史；输入法回车可能直接发送。
- 切换论文和翻译轮询缺少过期请求检查，旧论文结果可能覆盖新论文。
- 项目详情读取失败时一直显示“读取中”；导入/新建缺少统一忙碌与错误状态。

## 实施
1. 共用浮窗组件：拖动、键盘移动、缩放、最大化/恢复、重置、置顶、仅顶层 Escape 关闭、保留子组件状态、小屏边界。
2. 共用论文生命周期服务：项目与 PDF 作为同一实体，重命名同步到项目/论文库/阅读器，删除同步清理项目与 PDF（收藏独立保留）。旧无 PDF 项目仅作为待补充旧记录保留。
3. 项目列表增加 PDF 导入、直接阅读、搜索、统一重命名/删除论文项目，取消新建空项目入口；明确加载、失败与空状态。
4. URL 保存项目导航与阅读来源，补齐往返入口与状态同步；修复阅读异步状态和中文输入法发送。
5. 数据隔离测试、真实浏览器串联操作、代码复查；仅使用临时测试数据，不操作用户真实论文。

- `npm run check`：TypeScript、ESLint 通过；116 项测试通过。
- `npm run build`：通过，保留原有 5 条动态文件路径追踪警告（code-read/fs/platform，与本轮改动无关）。
- `tests/browser/interaction-consistency.mjs`：论文库/项目/阅读器改名同步、导航刷新、直接导入、删除失败重试、旧记录、窗口拖动/调整大小/收起/放大/还原/重置、聊天和追问草稿保留、输入法回车、键盘焦点置顶、顶层 Escape、小屏边界。
- `tests/browser/reading-memory.mjs`：公式、回答/译文划线追问、可点击高光、分支上下文、刷新恢复、手动收藏、PDF 多行选区与缩放。
- `tests/browser/reader-selection.mjs`：原生拖选、词语弹窗、显式收藏、点词与长选区共存、失败重试、过期请求、跨页和小屏。
