# 问答流式输出与阅读位置

需求：所有问答框流式输出；点击打开或查看回答时不要跳到末尾，应顺着正文阅读。

## 实现

- 划线追问（学习原文、PDF、翻译、回答中的子对话）、普通聊天与论文讲解、项目 AI 使用真实模型 SSE 流，经 NDJSON 返回前端；保留原有翻译流式接口。复现 copilot API 也支持相同流式协议。
- 通过 Accept: application/x-ndjson 协商流式，旧 JSON 调用保持兼容。最终事件沿用原有完整结果，包括历史记录、学习元数据或工具结果。
- SSE 解码处理 UTF-8 分片、工具参数分片、结束标记、异常中断和长度截断。中间文本只作临时展示，完整生成并校验后再写入阅读或项目对话；失败保留可读片段与重试提示。
- 移除划线问答中对窗口打开、忙碌状态和消息数量变化的 scrollIntoView。首次打开旧记录从头读，窗口关闭后重开保留位置。
- 新问题定位到新回答开头；内容增长不主动滚走。读者明确滚到末尾后跟随，向上阅读停止跟随；完成输出不跳转。隐藏窗口不更新滚动位置。
- 正在生成的 Markdown 暂不创建可保存选区，避免把还在变化的文字作为永久高光位置。

## 验证

- answer-stream.test.mjs：内容/工具增量、UTF-8 拆包、真实逐段到达、终态元数据、替换工具轮次文本、异常截断、取消，上述 5 项通过。
- api-answer-stream.test.mjs：阅读问答、普通对话、项目 AI 在模型结束前返回文字；阅读和项目历史在完成后才写入，学习元数据保留，2 项通过。
- browser/answer-streaming.mjs：模拟受控分批输出，验证学习追问及论文讲解的开头可见、关闭重开位置、上翻不抢滚动、主动跟随、完成位置稳定，通过。
- reading-highlights、study-shortcuts、notes-and-windows 浏览器回归通过。
- npm run check：类型检查、全量 lint 和 262 项测试通过。
- 最后补充隐藏窗口不跟随的保护后，相关 lint、流式浏览器测试及生产构建通过；构建仍有项目既有的动态文件访问追踪警告。
