# 论文库对话导入

用户授权实现：输入一串论文名或自然语言，由具有 PDF 导入权限的对话完成检索、下载和入库。

设计：论文库“对话导入”浮窗，保持原手动上传入口。独立持久化对话和逐篇工具结果；后台只能调用论文查找和从实际候选导入。复用 downloadPaper 的 PDF 验证、内容哈希去重和项目同步。导入成功显示阅读链接并刷新论文库；失败不影响其他论文。后台导入结果与 AI 解释分开展示，不能仅凭模型文字声称已入库。

候选规则：唯一精确标题、DOI、arXiv 身份匹配可直接导入；歧义或模糊查询须选择候选。没有 PDF 时给出来源入口，不创建空项目。支持多轮追加、候选确认、关闭重开查看进度、单篇重试；避免因刷新而重复提交。

任务：
- [x] 类型、持久化导入对话服务及 API：有限工具循环、可信候选 ID、任务认领防重复、实际结果和错误记录。
- [x] 检索补充准确 PDF 直链与 arXiv 解析，复用现有下载验证。
- [x] 浮窗与论文库入口：输入、逐篇状态、候选选择、继续/重试、历史恢复、自动刷新已导入项目。
- [x] 隔离服务测试、模拟多篇自然语言浏览器流程、真实检索只读探测、类型/Lint/构建及独立审查。

验证结果：`npm run check` 通过，177 项测试全部通过（新增检索测试 15 项、导入服务测试 18 项）。`npm run build` 成功，仍有 5 条既有动态文件追踪警告。`tests/browser/paper-import-chat.mjs` 模拟 API 回归通过，包括关闭重开、部分失败、无 PDF 后改选、网络恢复、历史恢复和移动端布局。

真实只读探测：arXiv 编号 1706.03762 返回正确论文与 PDF 地址；英文完整标题检索返回 OpenAlex 候选。同名记录不会直接认定为唯一匹配。测试没有调用真实付费模型或向用户论文库写入测试论文；下载/模型结果在服务测试中注入，实际下载和去重由现有隔离 API 生命周期测试覆盖。

审查修复：自动匹配必须对应用户实际提供的查询身份，不能由模型从歧义结果改写 DOI 绕过确认；指定 arXiv 版本不能自动替换。结构化澄清工具保存需要补充的信息；失败须显式重试；无 PDF 的候选允许重新选择。30 个新查询或 16 轮工具处理上限会保存继续处理提示。

## 真实混合清单修复（同日）

用户实际输入包含 20 个 UAV 论文简称、大量中文注释、嵌套平台/数据集说明和“都导入进 UAV 文件夹”。旧流程将中文说明拼进检索式，例如 `DroneFINE 无人机 目标检测 参数高效微调 VLM` 返回空；单独查询 `DroneFINE` 则返回正确论文。此前只验证简单英文标题与模拟工具序列，未覆盖这类自然语言输入。

按用户确认的方向增加独立 AI 前置整理：一次 DeepSeek JSON 请求提取 `name / context / original / targetGroup`，语义判断独立论文，保留原始简称，备注不进入标题查询。名称、原文引用和目标分组必须能对应用户输入，无法可靠整理时不会导入。普通查询、继续和澄清具有明确动作；完整队列先持久化，再逐篇检索/下载/分组，不再依靠模型连续发出 20 次检索工具调用。

检索修复：唯一标题冒号前名称可匹配简称；OpenAlex 匹配不清楚或缺 PDF 时补查 arXiv 的标题与摘要，按可信身份补充下载来源。不同作者的同名论文不能合并。状态区分未匹配、已找到但无 PDF、待选择与下载失败；保留批量重试，分组失败不重复下载。长原文/备注可展开，底部始终显示总数和目标分组。

真实验证：对用户完整原文实际调用 AI，得到 20 个主条目与 UAV 分组；TravelUAV 下的四个组成部分保留为备注。随后通过应用 API 恢复原失败会话，11 篇真实 PDF 已导入 UAV，合计 240 页，逐个核验 `%PDF-` 文件头及项目分组。余下 5 项待确认，DroneDINO / MCR-UOD / STEMFly 未匹配，MMGeo 未从检索源取得 PDF；没有用猜测结果补齐。验证记录位于 `.build-cache/uav-preprocessed.json`、`uav-search-probe.json`、`uav-import-recovery.json`、`uav-import-verification.json`。

独立审查补齐了两个回归：相同前缀的不同标题不能覆盖队列；继续处理时明确指定分组要应用到已有条目。构建通过，仍为既有 5 条动态追踪警告；浏览器模拟验证涵盖完整队列、长备注折叠、未匹配与无 PDF 状态、分组失败重试与批量重试。

最终 `npm run check` 全部通过：200 项测试、TypeScript、ESLint。运行中发现两项旧 handler 测试声称 mock 却依赖真实 Crossref/OpenAlex，造成偶发失败；已给这两项测试补充固定元数据与禁止未模拟请求的断言，未修改其生产流程。
