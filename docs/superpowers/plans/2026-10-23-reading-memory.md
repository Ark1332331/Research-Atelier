# 阅读追问与手动收藏

用户已明确要求改动，直接在当前工作区接续已有的 PDF 翻译改动。

## 交互约定
- AI 回答、整篇译文、选段译文共用数学 Markdown 和划选工具条。
- 蓝色是临时选区，紫色下划线是已保存的追问，黄色是生词收藏。紫色仅点击展开，不随光标移动弹出。
- 每个追问保存选中文字、来源、字符位置、相邻段落上下文及消息；支持连续追问、从回答再次选段、刷新回看与删除。
- 原文 PDF 追问保存文档指纹、页码及归一化矩形，缩放后仍可点击。
- 科研词汇手动加入术语卡片，英文词语手动加入生词本。停止导入抽取及补抽；旧卡片保留在历史入口。
- 去掉阅读页概念画像；卡片直接显示收藏释义与来源，复述记录退入可选历史内容。

## 实现顺序
1. 为数学语法兼容和追问存储添加边界测试；启用 remark-math/rehype-katex。
2. 实现共享阅读记忆存储、选区捕获、可点击高光与追问面板。
3. 接入 AI 回复、译文和 PDF；收藏操作复用现有数据文件，明确来源。
4. 停止自动抽取，简化术语工作区；保留历史数据。
5. 类型检查、lint、现有测试与真实 Chromium 交互回归；模型请求使用模拟响应，不消费用户额度。

## 验收
公式分式/上下标/块公式可读，代码不被误转；跨行选区、同文不同来源隔离、刷新恢复、追问失败重试、并发写入冲突、PDF 缩放、两类收藏都可验证。
