# 独立追问窗口与随心笔记

用户已授权描述清楚后直接实施。本轮限定以下三个交互，不新增自动学习功能。

- 生词本增加论文选择器（全部、具体论文、未关联论文），筛选保存在 URL，刷新和返回保持选择。
- 追问窗口以独立实例存在，草稿、发送状态、窗口位置分离；子窗口打开保留母窗口；关闭隐藏并保留记录和草稿；删除移除对应记录和高光，不级联删除独立子窗口。点击原高光或记忆列表可重新打开。
- 所有现有可划选翻译/追问的文字增加随心笔记，填写简短批注后手动保存。主工作台增加笔记库，可搜索批注、编辑、删除和按论文筛选。保留选区、上下文和来源元数据，点击后定位 PDF/译文/原聊天记录或追问；来源丢失时明确提示并显示摘录，不能伪造已定位。
