# 翻译后收藏与统一入口

按用户明确提出的流程实施：划选 → 翻译/释义 → 选择术语卡或生词本。

- 主界面内切换术语卡、生词本；原独立路由只做兼容跳转，保留论文筛选和术语定位。
- PDF、译文、AI 回答共用翻译结果组件；翻译完成前禁用收藏，失败保留结果与重试入口。
- 收藏保存当前展示的释义，不再次调用模型。术语新增独立释义字段，保留用户理解笔记及来源语境。
- 重复收藏不覆盖用户笔记；同一来源幂等，其他来源保留各自释义。
- 验证后端保存/拒绝空释义/去重与浏览器完整流程、旧链接、失败重试、移动布局；保持原阅读高光和追问能力。
